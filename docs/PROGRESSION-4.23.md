# Survivor dossier / 4.23

Design direction: a field manual with colored training routes, stamped equipment illustrations and compact overhead promotion notices. Preserve the existing coal (#142125), bone (#eee4cc), condensed display and mono labels; add amber arsenal, sage survival, coral hunter and ice-blue artificer accents. Status always includes text and icons. Use existing square controls with 44px targets and 8/12/16/24 spacing. No new gameplay buttons. Panel entrances use a 160ms fade/6px translation; selection and training feedback use short border/color transitions. Both system and in-game reduced-motion settings disable translation/animation.

Progression: existing saves keep testing access by default. A visible Testing / Hero progression selector controls actual simulation access. Hero progression starts with carbine, katana and fragmentation. Eight Arsenal training nodes unlock weapon families, elemental throwables and dual wielding. Existing character levels, points and skill prerequisites remain permanent. Free reallocation also relocks equipment whose training is removed. Discovered relics retain access to their base weapons. Testing bypasses equipment restrictions, but does not mark skills learned or spend points.

Asset audit: all 36 head/chest/leg armour combinations already have in-world geometry. Existing weapon portraits render actual models. Improve the inventory's vector illustrations to distinguish armour families and slots, fill empty-slot silhouettes, and reuse a complete vector icon set for skills/navigation. Raster generation is unnecessary for these small, scalable interface assets.

Verification: all 196 Node tests pass (including six new progression tests covering prerequisites, points, every weapon family, throwables, dual wield, respec, save normalization, earned relics, event lifetime and icon coverage). Production build passes; Three.js retains its existing chunk-size advisory. Browser checks confirmed Hero-mode SMG and dual-wield learning, prerequisite/point updates, the tiered armour inventory, and simultaneous overhead level/evolution notices. At a 390px phone frame the dossier content has matching 322px client/scroll widths, with a single-column tree and wrapping branch controls. This is responsive browser verification, not physical-phone or physical-controller testing.

Visual review: AI-slop score 1/10 (common UI fonts retain clear hierarchy); distinctiveness 8/10 (survivor dossier, colored route connectors, equipment silhouettes and compact combat notices). Dense training routes intentionally scroll on phones. No new external fonts, downloaded assets or particle emitters were added; notices are capped at three. Reduced motion is enforced in CSS and the overhead movement calculation. Existing progression saves remain valid and default to Testing access.
